# S6.10 Summary Persistence Implementation Plan

**Story**: [S6.10 Summary Persistence](../sprints/sprint_6/s6.10-summary-persistence.md)  
**Created**: September 21, 2025  
**Status**: Implementation Planning Complete

## Overview

Implementation plan for persistent summary storage with auto-save functionality on both `/app` and `/transcript/{id}` pages. This feature enables users to access their meeting summaries and action items across sessions while maintaining the existing seamless user experience.

## Current Architecture Analysis

### Database Foundation
- **Strong Entity Framework Core 9.0.0** foundation with proper relationships
- **User** entity for ownership and authentication
- **Meeting** entity for transcript relationships and metadata
- **MeetingHistory** entity for comprehensive audit trails
- Proper indexes and cascading delete configurations

### Frontend State Management
- **Zustand summaryStore.ts** with session-only persistence (browser storage)
- Complete CRUD operations for action items with proper TypeScript interfaces
- Auto-conversion of AI-generated action items to unified editable format
- Strong integration with Material-UI components and tour system

### Integration Points
- **API Service Factory** with mode-based routing (demo/development/production)
- **AppMode Context** for environment-aware behavior
- **Email Store** integration for summary sharing
- **Speaker Session Store** for speaker mapping persistence

## Implementation Strategy

### 5-Phase Incremental Approach
Each phase builds upon the previous while maintaining backward compatibility and providing incremental value.

### DbContext Configuration
```csharp
// Add to MeetingSummarizerDbContext.cs
public DbSet<SavedSummary> SavedSummaries { get; set; } = null!;
public DbSet<SavedActionItem> SavedActionItems { get; set; } = null!;

// Entity Configuration
modelBuilder.Entity<SavedSummary>(entity =>
{
    entity.HasKey(s => s.Id);
    entity.HasIndex(s => new { s.UserId, s.CreatedAt });
    entity.HasIndex(s => s.MeetingId);
    entity.HasIndex(s => s.LastAccessedAt);
    
    entity.HasOne(s => s.User)
        .WithMany(u => u.SavedSummaries)
        .HasForeignKey(s => s.UserId)
        .OnDelete(DeleteBehavior.Cascade);
        
    entity.HasOne(s => s.Meeting)
        .WithMany()
        .HasForeignKey(s => s.MeetingId)
        .OnDelete(DeleteBehavior.SetNull);
});

modelBuilder.Entity<SavedActionItem>(entity =>
{
    entity.HasKey(a => a.Id);
    entity.HasIndex(a => new { a.SummaryId, a.SortOrder });
    
    entity.HasOne(a => a.Summary)
        .WithMany(s => s.ActionItems)
        .HasForeignKey(a => a.SummaryId)
        .OnDelete(DeleteBehavior.Cascade);
});
```

### Auto-Save Implementation
```typescript
// Auto-save functionality
let autoSaveTimeout: NodeJS.Timeout | null = null;
let autoSaveConfig: { userId: string; transcriptFileName: string } | null = null;

const triggerAutoSave = () => {
  if (!autoSaveConfig) return;
  
  if (autoSaveTimeout) {
    clearTimeout(autoSaveTimeout);
  }
  
  autoSaveTimeout = setTimeout(async () => {
    const state = get();
    if (state.summary && state.actionItems.length > 0) {
      await state.saveSummary(
        `Auto-saved: ${new Date().toLocaleString()}`,
        autoSaveConfig.transcriptFileName
      );
    }
  }, 2000); // 2-second debounce
};

// Enhanced action implementations
saveSummary: async (title: string, transcriptFileName: string, meetingId?: string) => {
  const state = get();
  if (!state.summary) return;
  
  set({ saveStatus: 'saving' });
  
  try {
    const response = await apiService.saveSummary({
      title,
      transcriptFileName,
      meetingId,
      summaryData: state.summary,
      actionItems: state.actionItems
    });
    
    set({ 
      saveStatus: 'saved',
      selectedSummary: response.data 
    });
  } catch (error) {
    set({ 
      saveStatus: 'error',
      error: error instanceof Error ? error.message : 'Save failed' 
    });
  }
};
```

const SaveStatusChip: React.FC = () => {
  const { saveStatus } = useSummaryStore();
  
  const getStatusProps = () => {
    switch (saveStatus) {
      case 'saving':
        return { color: 'default', icon: <CircularProgress size={16} />, label: 'Saving...' };
      case 'saved':
        return { color: 'success', icon: <CheckIcon />, label: 'Saved' };
      case 'error':
        return { color: 'error', icon: <ErrorIcon />, label: 'Save Failed' };
      default:
        return null;
    }
  };
  
  const statusProps = getStatusProps();
  if (!statusProps) return null;
  
  return (
    <Chip
      size="small"
      icon={statusProps.icon}
      label={statusProps.label}
      color={statusProps.color}
      variant="outlined"
    />
  );
};
