# S8.9 - Automatic Speaker Name Extraction Implementation Plan

## Story Overview

**Story ID**: S8.9  
**Title**: Automatic Speaker Name Extraction  
**Priority**: High | **Effort**: 3-5 days | **Created**: November 9, 2025

**Objective**: Implement intelligent transcript analysis to automatically extract speaker names during transcription phase, eliminating speaker naming conflicts and improving user experience with pre-populated speaker mappings.

## Architecture Changes (Clean Design)

1. **Transcription Phase Enhancement**: Add speaker name extraction after Azure Speech Services returns transcript
2. **Summary Phase Cleanup**: Remove `ApplySpeakerMappings` from OpenAI service to eliminate naming conflicts  
3. **Single Source of Truth**: All speaker mapping happens during transcription phase only

- ✅ Consistent speaker labels throughout entire transcription → summary → export pipeline
- ✅ Backward compatibility with existing speaker mapping functionality

## Technical Requirements

### Speaker Name Extraction Patterns

```csharp
public class SpeakerNameExtractionService : ISpeakerNameExtractionService
{
    private readonly List<NameExtractionPattern> _patterns = new()
    {
        new NameExtractionPattern(
            @"\b(?:hi|hello|good morning|good afternoon),?\s+(?:this is|i'm|my name is)\s+([A-Za-z]{2,})", 
            0.9, // High confidence for explicit introductions
            RegexOptions.IgnoreCase
        ),
        new NameExtractionPattern(
            @"\b(?:i'm|im)\s+([A-Za-z]{2,})", 
            0.7, // Medium confidence for informal
            RegexOptions.IgnoreCase
        ),
        new NameExtractionPattern(
            @"\b([A-Za-z]{2,})\s+(?:here|speaking)", 
            0.6, // Lower confidence for context-dependent
            RegexOptions.IgnoreCase
        ),
        new NameExtractionPattern(
            @"\bthis is\s+([A-Za-z]{2,})", 
            0.8, // High confidence for direct introduction
            RegexOptions.IgnoreCase
        )
    };
}

public class NameExtractionPattern
{
    public string Pattern { get; }
    public double BaseConfidence { get; }
    public RegexOptions Options { get; }
}
```
