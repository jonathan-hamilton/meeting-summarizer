## Technical Implementation

### Architecture Components

**Core Components:**
- `FileUploadProgress.tsx` - Individual file progress with MUI LinearProgress
- `GlobalProgressIndicator.tsx` - Overall queue status with CircularProgress  
- `ProgressNotification.tsx` - Toast notifications for completion/errors
- `ProgressDashboard.tsx` - Detailed progress view (/progress route)

**Services:**
- `progressEstimator.ts` - File-size-based time estimation algorithms
- `progressPoller.ts` - Smart polling with exponential backoff
- `ProgressContext.tsx` - React context for progress state management

**State Management:**
- Enhanced `uploadQueueStore` with progress tracking
- Progress estimation and stage management
- Historical data for calibration

### Progress Estimation Algorithm

```typescript
// File-size-based timing:
// Small files (< 5MB): 30-60 seconds total
// Medium files (5-25MB): 1-3 minutes total  
// Large files (25MB+): 3-8 minutes total

// Processing stages:
// Upload (20%) → Processing (30%) → Transcribing (40%) → Summarizing (10%)
```

### Polling Strategy

- **Initial**: 1 second intervals for immediate feedback
- **After 30s**: 2 second intervals
- **After 2min**: 5 second intervals  
- **Maximum**: 10 second intervals
- **Stop when**: status === 'completed' || 'failed'
