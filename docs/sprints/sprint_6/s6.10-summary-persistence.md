# Story S6.10: Summary Persistence & User History Integration

## Overview
As a registered user, I want my generated meeting summaries and action items to be saved to my account so that I can access them from the History page and build a persistent library of my meeting insights.

**Status: PENDING ⏸️ (Ready for Implementation)**

**Completion Date:** TBD

### Phase 1: Database & API Foundation (2-3 hours)
**Foundation for all user summary storage**

#### Database Schema
```sql
-- Summaries table
CREATE TABLE Summaries (
    Id UNIQUEIDENTIFIER PRIMARY KEY DEFAULT NEWID(),
    UserId NVARCHAR(450) NOT NULL,
    TranscriptionId UNIQUEIDENTIFIER NOT NULL, -- Link to existing transcriptions
    TranscriptFileName NVARCHAR(500) NOT NULL,
    Summary NVARTEXT NOT NULL,
    CreatedAt DATETIME2 NOT NULL DEFAULT GETUTCDATE(),
    UpdatedAt DATETIME2 NOT NULL DEFAULT GETUTCDATE(),
    FOREIGN KEY (UserId) REFERENCES AspNetUsers(Id) ON DELETE CASCADE,
    FOREIGN KEY (TranscriptionId) REFERENCES Transcriptions(Id) ON DELETE CASCADE
);

-- Action Items table  
CREATE TABLE ActionItems (
    Id UNIQUEIDENTIFIER PRIMARY KEY DEFAULT NEWID(),
    SummaryId UNIQUEIDENTIFIER NOT NULL,
    Description NVARCHAR(1000) NOT NULL,
    AssignedTo NVARCHAR(200),
    Priority NVARCHAR(50) DEFAULT 'Medium',
    DueDate DATETIME2,
    Status NVARCHAR(50) DEFAULT 'Pending',
    CreatedAt DATETIME2 NOT NULL DEFAULT GETUTCDATE(),
    FOREIGN KEY (SummaryId) REFERENCES Summaries(Id) ON DELETE CASCADE
);

-- Performance indexes
CREATE INDEX IX_Summaries_UserId_CreatedAt ON Summaries(UserId, CreatedAt DESC);
CREATE INDEX IX_Summaries_TranscriptionId ON Summaries(TranscriptionId);
CREATE INDEX IX_ActionItems_SummaryId ON ActionItems(SummaryId);
```

### Frontend Store Architecture
```typescript
// summaryStore.ts (Zustand)
export const useSummaryStore = create<SummaryStore>()((set, get) => ({
  // Enhanced persistence methods
  saveSummaryToAccount: async (transcriptionId: string) => {
    const { currentSummary, actionItems } = get();
    if (!currentSummary) return;
    
    try {
      set({ isLoading: true });
      const summaryId = await apiService.saveSummary({
        transcriptionId,
        summary: currentSummary,
        actionItems
      });
      
      // Update local state
      set(state => ({
        persistedSummaries: [...state.persistedSummaries, {
          id: summaryId,
          transcriptionId,
          summary: currentSummary,
          actionItems,
          createdAt: new Date()
        }],
        isLoading: false
      }));
    } catch (error) {
      set({ isLoading: false });
      throw error;
    }
  }
}));
```
