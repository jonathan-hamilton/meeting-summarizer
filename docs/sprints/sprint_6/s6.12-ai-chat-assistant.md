### Actionable Response System
```typescript
// Action Types AI Can Trigger
interface ChatAction {
  type: 'navigate' | 'scroll' | 'dialog' | 'trigger';
  target: string;
  label: string;
}

// Action Handlers
const handleChatAction = (action: ChatAction) => {
  switch (action.type) {
    case 'navigate':
      router.push(action.target); // Navigate to page
      break;
    case 'scroll':
      scrollToComponent(action.target); // Scroll to element
      break;
    case 'dialog':
      openDialog(action.target); // Open specific dialog
      break;
    case 'trigger':
      triggerProcess(action.target); // Start app process
      break;
  }
  
  // Track action for analytics
  chatAnalyticsStore.getState().trackAction(action);
};

// Example AI Response with Actions
const aiResponseWithActions = {
  text: "I see you're looking for your summary. The summary appears below the transcript after generation.",
  actions: [
    { type: 'scroll', target: 'summary-section', label: 'Show me the summary' },
    { type: 'trigger', target: 'generate-summary', label: 'Generate summary now' }
  ]
};
```

## Technical Notes

- **Response Optimization**: Keep responses under 200 tokens to minimize costs
- **Context Efficiency**: Only send relevant context to AI, not entire app state
- **Error Resilience**: Graceful degradation when OpenAI API is unavailable
- **Privacy First**: No meeting content sent to AI, only workflow guidance
- **Session Management**: Ephemeral conversations, no cross-session persistence
- **Performance**: Lazy load chat components, minimize bundle impact
