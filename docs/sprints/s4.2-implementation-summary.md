- Error handling: Comprehensive logging and exception management

### ✅ Increment 4: Duration-Based Routing Logic (Complete)
**Files Modified:**
- `Services/AzureSpeechService.cs` - Added intelligent routing between real-time and batch APIs

**Technical Details:**
- **Duration Estimation**: File size-based algorithm with format-specific bitrate estimates
  - MP3: 128 kbps, WAV: 1411 kbps, M4A: 256 kbps, etc.
  - 10% safety buffer added to estimation
  - Graceful fallback to 5-minute estimate on errors
- **Smart Routing**: Configurable threshold (default: 90 seconds)
  - Short audio (≤90s): Real-time Azure Speech Services (existing flow)
  - Long audio (>90s): Azure Batch Transcription API (new capability)
- **Unified Interface**: Same `TranscribeAudioWithMetadataAsync` method signature
  - Transparent switching - no API changes for consumers
  - Comprehensive logging for service selection decisions
- **Configuration Integration**: Uses `MinimumDurationForBatch` from appsettings
- **Dependency Injection**: `AzureBatchTranscriptionService` injected into `AzureSpeechService`
