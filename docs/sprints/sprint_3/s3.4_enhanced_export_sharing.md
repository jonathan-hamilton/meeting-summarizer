## Overview

As a user, I want to generate AI-powered meeting summaries and share them via email so that I can quickly distribute key meeting outcomes and action items to participants while maintaining session-based privacy.

## Acceptance Criteria

**AI Summary Generation:**

- Manual "Generate Summary" button available after transcript and speaker mapping completion
- AI-generated meeting summary includes narrative overview (targeting one-page length, flexible for longer meetings)
- Action items section grouped by speaker using mapped names and roles
- Detection of both explicit assignments ("John, handle X") and implicit commitments ("I'll look into that")
- Unassigned action items clearly marked with "Not Assigned" notation
- Generated summaries editable within current session before sharing
- Integration with existing OpenAI service infrastructure

**Email Composition Interface:**

- Rich email composition interface with professional HTML formatting
- Pre-populated content with generated meeting summary and action items
- Company branding and professional styling applied to email templates
- Editable email content allowing users to modify before sending
- Multiple email sends supported during session (to different recipients)
- Email drafts saved and editable within current session

**Recipient Management:**

- Auto-suggest email recipients based on meeting participants from speaker mappings
- Manual recipient addition and removal capabilities
- Automatic inclusion of sender's contact information
- Support for multiple recipient groups and individual sends

**Content and Privacy:**

- Speaker roles and mappings included for recipient context
- Clear AI-generated content notification in all shared emails
- Session-based email composition with no persistent email storage
- No external links or dependencies (fully embedded content)
- Professional email formatting suitable for business communication

```typescript
// Email composition models
interface EmailDraft {
  subject: string;
  content: string;
  recipients: EmailRecipient[];
  createdAt: Date;
  lastModified: Date;
}

interface EmailRecipient {
  name: string;
  email: string;
  role?: string;
  source: 'participant' | 'manual';
}

// Email composition store
interface EmailCompositionState {
  draft: EmailDraft | null;
  recipients: EmailRecipient[];
  saveDraft: (draft: EmailDraft) => void;
  addRecipient: (recipient: EmailRecipient) => void;
  sendEmail: (emailData: EmailData) => Promise<void>;
}
```

- Email addresses stored only in session storage
- Real-time SMTP sending during active session
- Immediate data cleanup after successful send
- No persistent email storage or history
